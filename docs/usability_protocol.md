# 팀 밖 5명 사용성 평가 · 아직 미실시

이 문서는 바로 실행할 과제와 기록지이며, 실제 참가자 결과가 아니다.
목적은 광고와 공식 표시의 차이 및 출처를 찾을 수 있는지 확인하는 것이다. 합성 데이터의 상태 일치율과 합산하지 않는다.

## 준비

README대로 앱을 새 터미널에서 실행한다. 팀 밖 성인 5명을 모집하고 이름·건강상태·복약정보·개인 사진·화면 녹화는 수집하지 않는다.
참가자는 익명 U01~U05로 기록한다. 같은 PC와 화면 크기, 같은 합성 과제를 사용한다.
진행자는 정답이나 버튼 위치를 먼저 알려주지 않는다. 시작부터 30초를 재고 도움을 준 경우 반드시 기록한다.

## 공통 과제

1. S02 합성 광고를 업로드하고 인식 오류를 고친다. 제품명·업체명·신고번호를 보고 제품을 선택한다.
2. 결과 화면에서 “광고 문구와 공식 표시가 어디서 다른지 찾아 주세요.”라고 요청한다.
3. “이 정보의 출처 링크와 확인일을 찾아 주세요.”라고 요청한다.
4. 별도 탐색 과제: `홍삼정 앰플 프라임 면역력 증진에 도움`을 넣고 자료가 없다는 안내의 뜻과 다음 행동을 자신의 말로 설명하게 한다.

‘진짜/가짜를 맞혀 보세요’, ‘구매해도 될까요’ 같은 질문은 하지 않는다.
