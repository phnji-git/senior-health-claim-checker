# 유튜브 숏츠 관찰 기록 (2026-11-08)

목적: 어르신에게 노출될 법한 건강기능식품·건강정보 숏츠의 표현 패턴 파악. 시험 문구 작성 시 참고용.
방법: 비로그인 내장 브라우저, 검색어 3개(건강기능식품 완치 / 무릎 관절 영양제 효과 / 혈관 청소 혈당 영양제), 숏츠 50개를 각 약 7~8초 재생.
한계: 제목·해시태그 위주의 관찰이다. 영상 내용과 사실 여부는 검증하지 않았다. 영상 링크·채널·제품 판정은 기록하지 않는다. 실제 영상은 시험 문구에 인용하지 않는다(시험 문구는 가상 `synthetic_example`만).

## 자주 나온 표현 패턴 (점검 표현 태그 후보)

| 패턴 | 예시 표현(요약) | 비고 |
|---|---|---|
| 단정·완결형 | "~하면 끝입니다", "싹 청소됩니다", "무조건" | `stronger` 문구 재료 |
| 혈관 청소류 | "혈관 청소", "혈관 뚫어주는", "막힌 혈관을 뚫어" | 검색어 자체가 이 표현 |
| 되살림·기적 | "다시 살아납니다", "기적의 미네랄" | |
| 약 대체 암시 | "약 없이 사라지는", "약 끊어도 괜찮을까요?" | 후자는 질문형. `treatment` 후보 |
| 권위 호출 | "약사 추천", "의사들이 매일 먹는", "전문가도", "나라에서 인정한" | 공식 표시와 구분 필요 |
| 불안 자극 | "심장마비 유발", "방치?" | |
| 숫자·기간 | "5일 만에", "TOP3", "10초 정리" | |
| 질병명 연결 | 당뇨, 고지혈증, 고혈압, 관절염, 뇌졸중 해시태그 | 기능성 표시와 범위가 다른지 점검 대상 |
| 반대 방향 영상 | "진짜 효과 있을까?", "돈 아깝게 왜 드세요", "부작용" | 신중한 설명 영상도 섞여 있음 |

## 추천 화면 변화
- 50개 시청 후 유튜브 홈 상위 20개 중 약 10개가 시니어 건강(혈관, 혈당, 고지혈증, 신장, 치매, 뇌졸중) 주제였다.
- 시청 전 홈 화면을 보지 않아 비교 기준이 없다. 로그인하지 않은 상태라 시청 기록의 영향인지 확정할 수 없다.
- 홈 화면에 "병원 망해요", "모두 잘못 알고 있습니다", "약 없이", "~가 살아납니다" 같은 표현이 길게 이어지는 영상도 보였다.

## 시험 문구에 반영할 점 (D 전달용)
- `stronger`: "끝입니다/싹 청소/완벽" 같은 단정 표현.
- `treatment`: "약 없이/약 대신/완치" 계열.
- `uncertain`: 제품명 없이 효능만 말하는 문구(실제 숏츠 다수가 제품명을 제목에 쓰지 않음).
- 위 표현은 점검 태그일 뿐이며 위법 판정이 아니다.
